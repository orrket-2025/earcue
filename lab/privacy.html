EarCue 이어큐 개인정보 처리방침

시행일: 2026년 9월 4일

EarCue(이어큐, 이하 "앱")는 발표자가 준비한 대본을 문장 단위로 이어폰에 읽어주는 발표 보조 앱입니다. 앱은 개발자가 운영하는 서버를 두지 않으며, 사용자의 정보를 개발자에게 전송하거나 수집하지 않습니다.

1. 기기 안에만 저장되는 정보

  • 대본과 편집 내용: 사용자가 올리거나 붙여넣은 대본은 사용자의 기기 저장소(앱 데이터)에만 저장됩니다.
  • 내 목소리 녹음: 사용자가 직접 녹음한 음성과 AI로 생성한 음성 파일은 기기 안에만 저장됩니다.
  • 설정: 읽기 속도, 리모컨 버튼 배정, 글자 크기 등 설정값은 기기 안에만 저장됩니다.

앱을 삭제하면 위 정보는 모두 함께 삭제됩니다. 앱 안의 "이 대본 삭제"로 개별 대본과 녹음을 언제든 지울 수 있습니다.

2. 마이크 사용

마이크는 다음 두 기능을 사용자가 직접 켤 때만 사용됩니다. 그 외에는 마이크에 접근하지 않습니다.

  • 내 목소리 녹음: 문장을 녹음해 발표 때 재생하기 위해 사용합니다. 녹음은 기기 안에만 저장됩니다.
  • 말 인식(자동 진행): 발표자가 현재 문장을 말했는지 인식해 다음 문장으로 넘기기 위해 사용합니다. 안드로이드 앱에서는 기기의 음성 인식 기능을 사용하며, 기기가 온디바이스 인식을 지원하면 음성이 기기 밖으로 나가지 않습니다. 지원하지 않는 기기와 웹 브라우저 버전에서는 운영체제·브라우저 제공사(Google)의 음성 인식 서비스가 사용될 수 있으며, 이는 해당 제공사의 개인정보 처리방침을 따릅니다.

3. 선택 기능: ElevenLabs 연동

사용자가 자신의 ElevenLabs 계정 API 키를 앱에 입력하면, 대본 문장과 목소리 샘플 녹음이 사용자의 계정으로 ElevenLabs(elevenlabs.io)에 직접 전송되어 음성이 생성됩니다. 이 전송은 사용자가 "만들기" 또는 "생성" 버튼을 눌렀을 때만 일어나며, 개발자는 이 과정에 관여하거나 데이터를 받지 않습니다. API 키는 기기 안에만 저장됩니다. 해당 처리는 ElevenLabs 개인정보 처리방침을 따릅니다.

4. 수집하지 않는 것

앱은 계정을 만들지 않으며, 이름·이메일·위치·연락처·광고 식별자 등 어떤 개인정보도 수집하지 않습니다. 분석 도구나 광고 SDK를 포함하지 않습니다.

5. 인터넷 사용

웹 버전은 처음 열 때 앱 파일과 글꼴을 내려받습니다. 안드로이드 앱은 위 3항의 선택 기능을 쓸 때만 인터넷을 사용합니다.

6. 아동

앱은 특정 연령대를 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.
